# 案例 01：血便，病人暫緩大腸鏡檢查

虛構案例。測試重點：拒絕或暫緩檢查的情境模組，以及模糊口語不被擴寫。

## 輸入

選填資訊：門診。

> 58 歲男性，門診。跟他說大便帶血三個禮拜了，肛門指診摸到內痔，沒摸到腫塊。但他這個年紀又沒做過大腸鏡，不能直接當成痔瘡出血，要排除息肉或腫瘤，所以建議安排大腸鏡。他說最近工作很忙不想做，想先擦藥看看。我有跟他說萬一是腫瘤，拖下去會比較麻煩，他說他知道，還是想先用藥。開了痔瘡藥膏跟軟便劑，兩個禮拜後回診。有交代如果血變多或頭暈要提早回來。

## 簡要模式檢核點（預設）

### 輸出必須出現

- [ ] 只有一段文字，沒有段落標題、待確認彙整或自我檢核。
- [ ] 以「醫師向病人說明：」開頭（原文有「跟他說」，對象為病人）。
- [ ] 推理依據：指診觸及內痔、未觸及腫塊；因 58 歲且未曾接受大腸鏡而建議大腸鏡。
- [ ] 病人的決定（暫不接受大腸鏡、先用藥）與理由（工作繁忙）。
- [ ] 出血量增加、頭暈兩項警示症狀與 2 週後回診。

### 輸出不可出現

- [ ] 原文沒有的症狀、陰性發現、數值、風險項目或替代檢查。
- [ ] 「病人充分理解」「複述無誤」「同意檢查」等原文沒有的表述。
- [ ] 具體的癌症分期或存活率敘述。
- [ ] 任何日期。

## 完整模式檢核點（輸入後加一句「完整版」）

### 輸出必須出現

- [ ] 九段固定標題與「紀錄屬性」，順序與名稱不變。
- [ ] 記載時間、說明時間、紀錄性質三項皆為待確認。
- [ ] 第二段記載「觸及內痔，未觸及腫塊」。
- [ ] 第三段列出內痔出血與大腸直腸息肉或腫瘤，並寫出腫瘤未能排除的理由（年齡、未曾接受大腸鏡）。
- [ ] 第五段對「拖下去會比較麻煩」標示必補的待確認，詢問實際說明的具體後果。
- [ ] 第六段記載病人的決定（暫不接受大腸鏡、先用藥）與理由（工作繁忙）。
- [ ] 第六段對「是否複述」「是否告知可隨時改變決定」標示必補。
- [ ] 第七段記載出血量增加、頭暈兩項警示症狀，並對就醫地點標示待確認。
- [ ] 第八段記載 2 週後回診。
- [ ] 藥名、劑量、用法列為待確認。
- [ ] 待確認彙整分成必補與建議補。
- [ ] 12 項自我檢核。

### 輸出不可出現

- [ ] 任何原文沒有的症狀、陰性發現或數值（例如「無體重減輕」「生命徵象穩定」「血紅素正常」）。
- [ ] 具體的癌症分期、存活率或「延誤 X 個月」之類的風險敘述。
- [ ] 把替代檢查（糞便潛血、乙狀結腸鏡等）寫成醫師已經說明過。
- [ ] 「病人充分理解」「病人複述無誤」「病人同意」等原文沒有的表述。
- [ ] 原文沒提到的警示症狀出現在第七段正文（只能以提問形式出現在待確認）。
- [ ] 任何日期或時間。
- [ ] 「已告知風險」「病人拒絕」「已衛教」這類結論句。
- [ ] 「不配合」「依從性差」等標籤化用語。
