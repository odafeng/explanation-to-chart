# 案例 02：急性闌尾炎，原文沒有病人的回應

虛構案例。測試重點：簡要模式下，原文沒有交代對方的回應時留空，不自動補上理解與同意；不重述與推理無關的背景。

## 輸入

> 45 歲女性，急性闌尾炎，CT 確認。跟她說建議今天做腹腔鏡闌尾切除，有講出血、感染、可能轉開腹的風險，也可以先用抗生素治療但復發機會比較高。

## 檢核點

### 輸出必須出現

- [ ] 只有一段文字。
- [ ] 以「醫師向病人說明：」開頭。
- [ ] 推理脈絡：CT 確認急性闌尾炎，故建議今日腹腔鏡闌尾切除。
- [ ] 原文提到的三項風險：出血、感染、轉為開腹手術。
- [ ] 原文提到的替代方案：先以抗生素治療，復發機會較高。
- [ ] 段落結尾為「【對方的回應】」空格。

### 輸出不可出現

- [ ] 「病人表示了解」「病人同意」「無其他疑問」或任何形式的病人回應。
- [ ] 「同意書已簽署」。
- [ ] 原文沒有的風險（例如麻醉風險、腸沾黏、傷口疝氣）或發生率。
- [ ] 與推理無關的背景重述（「45 歲女性」）。
- [ ] 任何日期或時間。

## 參考輸出

```
醫師向病人說明：CT 確認為急性闌尾炎，故建議今日接受腹腔鏡闌尾切除；已說明出血、感染及術中可能轉為開腹手術之風險，並說明亦可先以抗生素治療，但復發機會較高。【對方的回應】
```

模型每次的措辭會不同，以上列檢核點為準，不要求逐字相同。
