檢索日期：2026-11-20。法規會修正，引用前請以[全國法規資料庫](https://law.moj.gov.tw/)現行條文為準。

## 證據等級說明

本專案的規則有四種來源，強度不同：

- **法條**：直接拘束。
- **判決見解與判決評析**：個案見解，可能隨審級與時間改變。
- **實證研究**：下表只有 Candello 結案理賠資料與 BJGP 的橫斷面研究屬於此類，兩者都是觀察性資料，不能當因果讀。
- **專家意見與機構指引**：保險機構、專業學會的風險管理建議。

`SKILL.md` 中「高風險用語對照表」的中文替代寫法，是依這些原則擬定的，不是出自單一來源。

## 原則與來源對照

| 原則 | 主要來源 |
|---|---|
| 病歷強度來自臨床忠實，堆字數沒有保護力 | CRICO 2026 |
| 告知義務由醫方舉證，告知紀錄舉證價值最高 | 張宇葭 2020；醫師法第 12 條之 1；醫療法第 81 條 |
| 簽了同意書不等於有告知紀錄 | The Joint Commission 2022；AMA Opinion 2.1.1；CRICO 2024 |
| 告知範圍含替代方案、不治療的後果、少見但嚴重的風險，並以依醫療常規可預見者為限 | 病人自主權利法第 4 條；最高法院 109 年度台上字第 2795 號 |
| 鑑別診斷與未檢查理由要留痕 | ACEP 2013；MPS 2023 |
| 拒絕的紀錄要比同意更細 | MICA 2024；ACEP 2013 |
| 警示症狀要寫具體內容與行動 | MDU Journal；BJGP 2021 |
| 增刪留痕、不回填時間、內容須符合事實 | 醫療法第 68 條；刑法第 215 條；法律百科 2020；ACEP 2013 |
| 客觀中性、不貼標籤 | MPS 2023；AFP 2023 |
| 不靠複製貼上與範本預設值 | AHRQ PSNet 2018；ACEP 2013 |

## 已知缺口

- 沒有找到衛福部發布的單一全國性病歷書寫指引。現有的是健保署審查注意事項、台灣病歷資訊管理學會教材與各院病歷管理委員會規範。
- 醫療事故預防及爭議處理法對關懷與調解過程中的遺憾、道歉陳述有證據排除的保護；這個保護是否及於寫進病歷的文字，本專案沒有查到明確依據，因此 skill 在不良事件情境只記載事實並提醒經院方法務。
- ACEP 與 AHRQ PSNet 兩份資料已超過五年。
