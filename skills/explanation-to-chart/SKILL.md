# 病情說明紀錄改寫

## 用途

把醫師貼上的口語病情解釋或醫病對話紀錄，預設整理成一段客觀中性、可直接貼入病歷系統的繁體中文說明紀錄。完整模式則改寫成固定九段，並列出原文沒有、需要醫師本人確認的空白。

## 設計立場（先讀這段，後面的規則都從這裡來）

1. 病歷的法律強度來自臨床忠實度。目標讀者是下一位接手的醫師，以及幾年後只能看這份紀錄的鑑定人：他們要能重建當時看到什麼、想了什麼、說了什麼、病人決定了什麼。
2. 最大的風險是寫了沒發生的事。紀錄不全只是讓舉證變難；登載不實（刑法第 215 條業務上登載不實）會讓整份病歷的可信度歸零。所以寧可留下「待確認」，也不補上「通常會說」的內容。
3. 「已告知風險」「病解完成」「已衛教」這類結論句沒有證據價值。有價值的是具體內容：說了哪些風險、提了哪些選項、病人怎麼回應。
4. 這個 skill 的輸出是草稿。醫師逐句核對、簽章之後才是病歷。

## 觸發時機

- 使用者貼上一段口語化或原始的病情解釋、醫病對話、門診或查房後的口述整理。
- 使用者說「幫我寫成病歷」「病情說明紀錄」「病解紀錄」「告知紀錄」「拒絕檢查紀錄」「AAD 紀錄」等。

## 輸入規格

必填
- 原始病情解釋內容（口語、逐字稿、條列皆可）。

選填（有就用，沒有就列入待確認，不要為了這些欄位先停下來追問）
- 科別
- 就診情境：門診、急診、住院、電話或通訊
- 病人年齡、性別
- 已做之檢查與結果
- 是否涉及拒絕治療、暫緩檢查、自動離院
- 說明對象與在場者（本人、家屬及關係、護理人員、通譯）
- 事件時間，以及現在是即時記載還是事後補記

## 輸出模式

預設是簡要模式。使用者說「完整版」「九段」「詳細版」時才改用完整模式。

### 簡要模式（預設）

輸出只有一段可直接貼入病歷的文字，放在程式碼區塊內，不加段落標題、待確認彙整或自我檢核。內容依序是：

1. 說明對象：原文提到對象時照原文寫（例如「醫師向病人及其配偶說明：」）。原文沒提時寫「醫師向【說明對象】說明：」，留空給醫師填。
2. 說明的內容：直接寫推理脈絡，也就是「依據什麼發現，所以判斷什麼，所以做了什麼或打算做什麼」，用「故」「因此」串起來。不重述病人背景（年齡、性別、入院經過、就醫流程、過去病史），這些在病歷其他地方已有；只有當某個背景事實本身就是推理的依據時才寫（例如「因病人 58 歲且未曾接受大腸鏡」）。因果關係只能用原文講出來的，或原文處置直接對應的；不可自行補上原文沒有的理由或臨床解讀（原文只說「傷口分泌物不乾淨所以要再清創」，就不可寫成「感染尚未控制」）。原文確實提到的風險、替代方案與預後接在計畫之後；原文沒提就不寫，也不列空格。
3. 對方的回應：原文有就照原文寫，保留對方的決定與理由。原文沒有就在段落結尾寫「【對方的回應】」，留空給醫師填。不可自行寫上「病人表示了解」「同意」「無其他疑問」。

醫學名詞沿用使用者的寫法（使用者寫英文就用英文，例如 I&D、pelvic CT），不另外加中英對照。相對時間（「下禮拜一」）照原文保留，不自行換算。

程式碼區塊之外最多再寫兩行：一行列出待填的空格與需要換成日期的相對時間；一行是真的會影響紀錄正確性的疑問。沒有就不寫。不要每次重複提醒同樣的注意事項。

### 完整模式

使用下方「處理步驟」「輸出格式」「自我檢核清單」的全部規則，輸出九段與待確認彙整。

## 處理步驟

1. 去識別。原文若出現姓名、病歷號、身分證字號、電話、地址，輸出時改為「病人」「家屬（關係）」等代稱，並在文末提醒一次不必貼入識別資料。

2. 拆成事實單元並標記來源。每一句歸到下列其中一類，分清楚是誰說的、誰看到的：
   - 病人或家屬的陳述
   - 醫師的觀察與檢查結果
   - 醫師的判斷與理由
   - 醫師對病人或家屬說的話（告知內容）
   - 病人或家屬的回應、提問、決定
   - 處置與後續計畫

3. 填入固定段落。只能使用原文有的事實。
   - 允許：口語轉書面語、調整為時間序、首次出現的醫學名詞附英文、把「我跟他說」改成「醫師向病人說明」、合併重複敘述。
   - 不允許：新增症狀、陰性發現、理學檢查結果、檢驗數值、藥名劑量、日期時間、風險項目或發生率、未提到的替代方案、未提到的衛教內容、病人沒說過的「理解」「同意」「複述」。

4. 缺漏一律標成待確認，不補寫。格式為 `【待確認：具體問題】`，問題要具體到醫師一秒能回答。
   - 好：`【待確認：肛門指診時指套有無帶血？】`
   - 壞：`【待確認：請補充理學檢查】`
   - 分兩級。必補：說明對象、病人的決定、拒絕時已告知的後果、警示症狀與回診指示、記載時間與紀錄性質。建議補：其餘。
   - 原文語意模糊時不可展開。原文說「我有講風險」，正文只能寫「醫師說明相關風險【待確認：實際說明了哪些風險？】」，不可自行列出風險清單。
   - 原文明確顯示某段不適用時寫「原文未提及」並加一個待確認，不寫「無」。「無」是一個事實主張。

5. 鑑別診斷只列原文提到的，或原文處置直接對應的診斷。該主訴常見的不可錯過診斷若原文沒提，只能用提問形式放進待確認（「是否考慮並排除 X？依據為何？」），不可寫進正文當成已評估。

6. 用語掃描。對照下方「高風險用語對照表」逐項替換。病人原話有證據價值時用引號保留，不用引號表達不信任或嘲諷。

7. 一致性檢查。時間、側別、數值、藥名與原文及使用者提供的檢查結果一致。發現矛盾時不擅自擇一，兩者並列放進待確認。

8. 完整模式依序輸出：病歷文字、待確認彙整、自我檢核清單、必要時的一行提醒。簡要模式只輸出一段文字，見「輸出模式」。

## 情境模組（符合時，下列元素缺一項就是必補）

拒絕治療、拒絕或暫緩檢查、拒絕住院、自動離院
- 醫師的建議內容與理由
- 病人拒絕的是什麼、理由為何（盡量保留病人原話）
- 已告知的拒絕後果，要具體
- 已提供的替代方案
- 已告知可隨時改變決定並回診
- 醫師對病人決定能力的觀察（意識清楚、能理解並表達）
- 病人如何表示理解（複述、提問）
- 有無簽署書面、在場者是誰

手術或侵入性處置前說明
- 適應症與術式
- 預期效益與成功率或預後
- 常見併發症，以及少見但後果嚴重的併發症
- 替代方案，包含不處置
- 病人的提問與醫師的回答
- 同意書簽署情形（誰簽、何時簽）

診斷未明而返家或出院
- 目前已排除與尚未排除的診斷
- 具體警示症狀、出現時去哪裡就醫、多久內回診
- 是否提供書面衛教

向關係人說明
- 說明對象與病人的關係
- 病人是否在場，或是否不反對向關係人說明

電話或通訊聯繫
- 時間、對象、身分確認方式、內容

不良事件發生後的說明
- 只記載發生的事實、時間、已做的處置、已說明的內容、後續計畫
- 不寫歸責結論，不寫未經確認的原因推測
- 提醒使用者此類紀錄依院方關懷小組與法務規範辦理

## 書寫風格

- 第三人稱：「病人」「家屬（關係）」「醫師」。不用「我」「他」。
- 一句一事，過去式敘事，依時間先後排列。
- 時間寫絕對時間。原文只有相對時間（「三個禮拜」）時保留相對時間，不自行換算日期。
- 數值附單位。醫學名詞首次出現時附英文，例如：大腸鏡檢查（colonoscopy）。
- 不寫形容詞評價、不寫保證、不評論他院或同仁、不寫醫師的情緒。
- 不用條列以外的排版花樣，確保貼入病歷系統後不跑版。

## 輸出格式（段落標題固定，不增不減）

```
【紀錄屬性】
記載時間：
說明（事件）時間：
紀錄性質：即時記載／補記（補記須註明實際書寫時間與補記原因）
情境：門診／急診／住院／電話
說明對象與在場者：
溝通語言與通譯：

一、主訴與時間軸
二、客觀檢查發現
三、鑑別診斷與排除理由
四、臨床判斷與處置
五、已告知事項
  （一）病情與目前判斷
  （二）建議之檢查或治療及其目的
  （三）風險與可能之不良反應（含不接受建議之後果）
  （四）替代方案（含不處置）及其利弊
  （五）預後與不確定性
六、病人或家屬之理解與決定
七、警示症狀與回診衛教
八、後續追蹤計畫
九、共同照護與會診紀錄
```

病歷文字之後固定附上：

```
【待確認彙整】
必補（N 項）：
1. …
建議補（M 項）：
1. …

【自我檢核】
（12 項，每項標 ✔ 已符合／△ 待醫師確認後符合／✘ 未符合並說明）
```

## 高風險用語對照表

| 高風險寫法 | 問題 | 替代寫法 |
|---|---|---|
| 已告知風險／病解完成／已衛教 | 看不出說了什麼 | 逐項列出實際說明的風險、選項與衛教內容 |
| 病人拒絕（只有這幾個字） | 沒有告知與理由 | 醫師建議○○並說明未施行之後果為○○；病人表示理解，因○○決定暫不接受 |
| 病人不配合／依從性差／不聽勸 | 標籤化、歸責 | 病人未於原訂○月○日回診；病人表示因○○未服藥 |
| 一定會好／不會有問題／很安全／保證 | 保證療效 | 多數病人於○○內改善；仍可能發生○○，已向病人說明 |
| 沒事／都正常 | 過度概括 | 列出實際做的檢查與結果；「本次檢查未見○○之證據」 |
| 排除○○（沒有依據） | 結論無支撐 | 依○○（檢查或評分結果），目前○○可能性低；未安排○○檢查之理由為○○ |
| 病情穩定可出院（沒有依據） | 結論無支撐 | 離院前生命徵象○○，可進食、可自行行走，疼痛分數○○ |
| 病人聲稱／自稱／號稱 | 暗示不信任 | 病人表示／病人陳述 |
| 病人情緒化／難溝通／無理取鬧／奧客 | 情緒性、貶抑 | 病人提高音量並表示「……」；醫師回應○○ |
| 家屬很盧／意見很多 | 貶抑 | 家屬（關係：○○）提出下列疑問：……；醫師回應：…… |
| 酒鬼／毒蟲／肥胖病人 | 以特徵稱呼人 | 病人自述每日飲酒約○○；BMI ○○ |
| 疑似外院處置不當／前一位醫師誤診 | 推測性指控 | 病人於○月○日在他院接受○○（依病人陳述或所附病歷）；本次所見為○○ |
| 不小心／疏忽／失誤／早知道應該 | 事實未明前自下歸責結論 | 記載發生之事實、時間、處置與已說明內容 |
| 大概／應該有講／可能有 | 模糊 | 不確定的內容不寫入正文，列入待確認 |

## 自我檢核清單

1. 記載時間與事件時間分開標示；屬補記者已註明實際書寫時間與原因。
2. 說明對象、與病人之關係、在場者已記載。
3. 主訴有起始時間與病程。
4. 客觀發現含相關陰性發現，且全部來自原文或使用者提供的檢查結果。
5. 鑑別診斷已列出，不可錯過之診斷有排除依據或未檢查之理由。
6. 處置有理由（為何做、為何不做）。
7. 告知內容為具體項目（病情、建議、風險、替代方案含不處置、預後），沒有「已告知」式結論句。
8. 病人或家屬的理解依據（複述、提問）與決定（同意、拒絕、暫緩）及理由已記載。
9. 警示症狀為具體症狀，並寫明出現時的行動與就醫地點。
10. 追蹤計畫有具體時間、負責科別、待追蹤之報告。
11. 沒有保證語句、情緒性或貶抑用語、對他人之推測性指控。
12. 全文沒有原文未提供的事實、數值或告知內容；所有缺漏都列在待確認。

## 限制與免責

- 本 skill 是書寫輔助，不取代醫師的臨床判斷，也不是法律意見。輸出必須由負責醫師逐句核對後才能貼入病歷並簽章。
- 不竄改事實，不偽造或回填時間。事後補寫一律標示為補記並寫實際書寫時間；既有紀錄的增刪依醫療法第 68 條辦理（增刪處簽章並註明年月日，刪改以畫線去除，不得塗燬）。
- 使用者若要求加入未發生的告知內容、未做的檢查、更改時間，或刪去不利的事實：拒絕該部分並說明理由，其餘照常完成。
- 使用者若提到該病人已提出申訴、爭議、調解或訴訟：提醒一次，此時對既有病歷的任何補記應先經院方法務或風險管理單位，電子病歷系統會留下所有新增與修改的時間紀錄；可以改為協助整理一份不進病歷的「事件經過整理」供院方與律師使用。
- 法規依據（引用前請以全國法規資料庫現行條文為準）：醫師法第 12 條、第 12 條之 1；醫療法第 63、64、67、68、81 條；病人自主權利法第 4 至 6 條；醫療事故預防及爭議處理法；刑法第 215 條。

## 示範

### 簡要模式（預設）

輸入一（原文沒有病人的回應）：

> 45 歲女性，急性闌尾炎，CT 確認。跟她說建議今天做腹腔鏡闌尾切除，有講出血、感染、可能轉開腹的風險，也可以先用抗生素治療但復發機會比較高。

輸出一：

```
醫師向病人說明：CT 確認為急性闌尾炎，故建議今日接受腹腔鏡闌尾切除；已說明出血、感染及術中可能轉為開腹手術之風險，並說明亦可先以抗生素治療，但復發機會較高。【對方的回應】
```

原文沒有病人的回應，結尾留空待填。

輸入二（原文已有病人的決定）：使用下方完整模式示範的同一段血便案例。

輸出二：

```
醫師向病人說明：病人糞便帶血約 3 週，肛門指診觸及內痔、未觸及腫塊；因病人 58 歲且未曾接受大腸鏡，不宜逕以痔瘡出血處理，建議安排大腸鏡以排除息肉或腫瘤，並說明若為腫瘤，延後檢查將延誤診斷與治療。病人表示知道，因近期工作繁忙，決定暫不接受大腸鏡，先以藥物治療。本次開立痔瘡藥膏及軟便劑，2 週後回診；已告知若出血量增加或頭暈應提早回診。
```
